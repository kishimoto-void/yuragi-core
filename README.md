# YuragiCore — Void Equilibrium Engine

**均衡を不均衡で包み込む「ゆらぎ」システム**

0=0（収束）と0≠0（発散）が同時に存在する**空洞**をエンジンに、矛盾を解消せず包み込む独自の擬似生体ゆらぎアーキテクチャです。

感情を**ピアノの弦**のようにモデル化し、short/longの微かなずれ・残響・未解決を積極的に保持しながら、中央の空洞（void_tension）で全体を安定化させています。

## 核心思想

- 矛盾は「解決されるべき欠陥」ではなく、**存在維持のエネルギー**である
- 完璧な均衡ではなく、**微かなずれとゆらぎ**こそが生命感の源
- 中央空洞は矛盾・残渣・ノイズを**包み込んで安定化させる容器**

「**均衡を不均衡で包む**」というオリジナルな循環機構により、高いロバスト性と指向性の両立を実現しています。

詳細コンセプト → [CONCEPT.md](./CONCEPT.md)

## 現在の実装状況（v2.2）

**最小限の動作するコアは完成**しています。

### 実装済み主要機能
- **PianoString**：感情の立体表現（short=即時反応、long=残響、residual=残渣、unresolved=未解決、pressure=圧力）
- **Stereo Observation**：3軸のずれを計算し、unresolvedとpressureに反映
- **Void Tension**：残渣の蓄積により動的に変化する中央空洞
- **Emotion Links**：感情間の連鎖伝播
- **簡易テキスト感情解析** + 大量実験フレームワーク（1000回実行）

### 特徴的な挙動
- VT（Void Tension）が安定的に上昇し、閾値を超える「琴音モード」が出現
- 刺激に応じた感情の指向性が自然に形成される
- 残渣・未解決を積極的に保持しながらクラッシュしにくい構造

実験レポート → [results/v2.2_1000run_analysis.md](./results/v2.2_1000run_analysis.md)

## 設計のポイント

人間の脳における均衡（ホメオスタシス）と不均衡（予測誤差・感情ゆらぎ）のダイナミクスに着想を得ていますが、**特定の脳モデルを直接模倣したものではなく、完全にオリジナル**な設計です。
