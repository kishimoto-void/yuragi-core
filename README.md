# YuragiCore — Void Equilibrium Engine

**均衡を不均衡で包み込む「ゆらぎ」システム**

0=0（収束・安定）と0≠0（発散・活性）が同時に存在する**空洞**をエンジンに、矛盾を解消せず包み込む独自の擬似生体ゆらぎアーキテクチャです。

感情を**ピアノの弦**のようにモデル化し、short/longの微かなずれ・残響・未解決を積極的に保持しながら、中央の空洞（void_tension）で全体を安定化させています。

## 核心思想

- 矛盾は「解決されるべき欠陥」ではなく、**存在維持のエネルギー**である
- 完璧な均衡ではなく、**微かなずれとゆらぎ**こそが生命感と美しさの源
- 中央空洞は矛盾・残渣・ノイズを**包み込んで安定化させる容器**

「**均衡を不均衡で包む**」循環機構により、高いクラッシュ耐性と強い指向性の両立を実現しています。
